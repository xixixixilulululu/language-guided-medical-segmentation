## 5. Files written by the frozen analysis programs that are not used for any decision

`src/phase2/analyze_phase2.py` (frozen; not changed) always applies the Phase 3 go / no-go rule of
PHASE2_PROTOCOL.md section 5.1 to the split it analyses. On the test split it therefore also wrote:
- `results/phase2_phase3_rule_test.csv`
- `results/phase2_phase3_per_donor_test.csv`
- `results/phase2_phase3_outcome_test.json`

These are **descriptive only and not the basis of any decision**. The go / no-go rule uses validation only and is
not re-applied on test (PHASE2_PROTOCOL_FREEZE.md section 4); the Phase 3 decision was taken on validation and
recorded before the freeze (`configs/phase2_frozen/phase3_decision.json`). Their contents are not reported here.
The program also prints the rule outcome with the label "(validation)" whatever the split; on the test run that
label is wrong. It is fixed text in the frozen code and is not changed.
